Difference between encodeURI and encodeURIComponent

  • encodeURI: Encodes a complete URI by escaping characters not permitted in URIs, while preserving reserved characters with syntactic meaning (e.g. :, /, ?, &, =).
  • encodeURIComponent: Encodes all characters including reserved URI delimiters, making it suitable for encoding individual query string values and parameters.
