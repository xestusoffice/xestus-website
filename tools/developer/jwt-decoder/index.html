What is a JSON Web Token (JWT)?

A JSON Web Token (RFC 7519) is a compact, URL-safe means of representing claims to be transferred between two parties. The claims in a JWT are encoded as a JSON object that is digitally signed using a cryptographic algorithm (such as HMAC SHA-256 or RSA).

JWT Token Anatomy

  • Header: Contains token type (JWT) and signing algorithm (e.g. HS256, RS256).
  • Payload: Contains claims such as sub (Subject), iss (Issuer), exp (Expiration), and iat (Issued At).
  • Signature: Cryptographic hash created using the encoded header, payload, and secret key.
