Regular Expression Quick Reference

  • \d: Any digit [0-9] | \D: Non-digit
  • \w: Word character [a-zA-Z0-9_] | \W: Non-word character
  • \s: Whitespace (space, tab, newline) | \S: Non-whitespace
  • ^: Start of string / line | $: End of string / line
  • +: 1 or more times | *: 0 or more times | ?: Optional (0 or 1)
  • {min,max}: Specified quantifier range (e.g. {2,4})
  • (?<name>...): Named capture group
