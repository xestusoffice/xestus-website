About the Base64 Encoder & Decoder

The XESTUS Base64 Encoder & Decoder is a high-speed developer utility for converting text, JSON payloads, and binary data into ASCII-safe Base64 strings and vice versa. Base64 encoding is widely used across web development, REST APIs, email protocols (MIME), data URI embeds, and authentication tokens to safely transmit binary data through text-only transmission channels. Unlike online tools that upload your text or credentials to a remote server, XESTUS runs entirely within your browser's local JavaScript environment, ensuring that API keys, passwords, and sensitive configurations remain completely private.

Mathematical Formulas & Technical Mechanics

Under the hood, calculations and operations strictly adhere to validated standards:

Base64 Encoding Algorithm Mechanics (RFC 4648)
1. Convert input characters into 8-bit binary bytes (UTF-8).
2. Group consecutive bytes into 24-bit chunks (3 bytes = 24 bits).
3. Split each 24-bit chunk into four 6-bit integers (2^6 = 64 possible values).
4. Map each 6-bit value (0-63) to the Base64 character set:
   [A-Z = 0-25, a-z = 26-51, 0-9 = 52-61, + = 62, / = 63]
5. Add '=' padding if input byte count is not divisible by 3.

Worked Example: Base64 Encoding

Encoding plaintext: "Hello XESTUS"
  • ASCII Bytes: 72 101 108 108 111 32 88 69 83 84 85 83
  • Base64 Encoded: SGVsbG8gWEVTVFVTCg==
  • Decoding: Decoding SGVsbG8gWEVTVFVTCg== returns exactly "Hello XESTUS".
