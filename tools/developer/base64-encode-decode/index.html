What is Base64 Encoding?

Base64 is a binary-to-text encoding scheme that represents binary data in an ASCII string format by translating it into a radix-64 representation. It is widely used for embedding images in HTML/CSS, transferring data in email via MIME, and transmitting data in JSON Web Tokens (JWT).

Standard vs. URL-Safe Base64

  • Standard Base64: Uses + and / with = padding.
  • URL-Safe Base64 (RFC 4648 §5): Replaces + with -, / with _, and often omits padding so the string can be placed safely in URL query parameters without percent-encoding.
