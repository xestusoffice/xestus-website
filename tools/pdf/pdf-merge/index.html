About In-Browser PDF Merging

The XESTUS PDF Merger is a client-side document compiler built with WebAssembly and JavaScript engines. While conventional PDF combining sites upload your sensitive papers (identification cards, bank statements, academic records) to unverified remote servers, XESTUS reads the PDF binary streams directly inside your browser memory and produces a merged file without sending a single byte across the internet.
